# 🤝 Contributing to rtl-text-tools

Contributions are welcome! Please feel free to submit a Pull Request.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Create your feature branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **Make your changes** and ensure your code is tested.
4. **Commit your changes**:
   ```bash
   git commit -m 'Add some amazing feature'
   ```
5. **Push to the branch**:
   ```bash
   git push origin feature/amazing-feature
   ```
6. **Open a Pull Request** against the `main` branch.

## Reporting Bugs & Suggesting Features

If you find a bug or have an idea for a new feature, please open an issue on [GitHub](https://github.com/homayounmmdy/rtl-text-tools/issues) so we can discuss it!

Thank you for helping improve `rtl-text-tools`!
